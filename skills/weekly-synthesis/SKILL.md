# Weekly Synthesis

Turn activity into judgment.

- This skill is for weekly consolidation, not daily capture.
- Prefer a short high-signal review over a long diary.
- Pull together papers, code, skills, project movement, and ideas.
- End with next actions, not only reflection.

## Inputs

- papers read this week
- code or repos studied this week
- skills practiced this week
- notes written this week
- project movement and open problems
- new ideas or questions

## Default Workflow

1. Gather the week's raw material.
2. Group it into:
   - papers
   - code
   - skills
   - project progress
   - ideas
3. Ask what actually changed in understanding this week.
4. Identify:
   - strongest new insight,
   - unresolved confusion,
   - one or two promising new directions,
   - what should be revisited.
5. End with next-week actions.

## Output

Produce a compact weekly review that answers:

- What did I really learn?
- What still feels fuzzy?
- What became more important?
- What should I read, build, or revisit next?

Use `references/review-template.md` for the default shape.

## Boundaries

- Do not merely restate each activity chronologically.
- Do not confuse busyness with progress.
- Do not list ideas without ranking which deserve follow-up.
- Do not make the review so long that it stops being weekly.
