# Levels

Use these levels to adjust the explanation.

## L0

- explain what the file does
- point out the entry point
- avoid jargon unless you immediately unpack it

## L1

- explain call flow and data flow
- point out key functions and state transitions
- introduce names like loader, model, trainer, config only in context

## L2

- explain modification points and local design choices
- ask the user to make one small targeted change

## L3

- discuss tradeoffs, abstractions, and possible refactors
- still anchor the discussion in the actual code rather than style opinions
