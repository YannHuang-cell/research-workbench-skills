# Teacher Or Supervisor Report Template

Use this structure only when the user explicitly wants a longer report.

## Required Sections

1. 论文基本信息
2. 一句话主旨
3. 研究问题与背景
4. 核心方法
5. 数据、实验与评价
6. 主要结果
7. 创新点
8. 局限性
9. 补充信息、数据与代码
10. 本次阅读中卡住的点
11. 对用户的学习建议
12. 拓展思考

## Writing Guidance

- Keep Chinese clear and concrete.
- Separate paper claims from your interpretation.
- Mention repeated confusion points if they mattered during the session.
- Prefer numbers, tables, and concrete evidence when visible.

## Short Alternative

If the user does not need a full report, output only:
- 论文主旨
- 方法主线
- 关键证据
- 当前仍不确定的点
