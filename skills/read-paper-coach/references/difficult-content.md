# Difficult Content

Use this file when formulas, figures, tables, pipelines, or ablations are the main obstacle.

## Formula

- State what the formula is for before reading symbols.
- Name only the symbols that matter right now.
- Explain what each main term is pushing the system to do.
- If needed, use a toy example instead of repeating the full notation.

## Figure

- Identify the figure type first.
- Read axes, legend, and units before interpreting trends.
- State the single claim the figure is meant to support.
- Say what remains uncertain if labels are unreadable.

## Table

- State what rows and columns represent.
- Clarify whether higher or lower is better.
- Point to the smallest part of the table that carries the main evidence.

## Method Or Pipeline

- Explain in this order:
  - input,
  - main modules,
  - output,
  - loss,
  - train/infer difference,
  - why the order matters.

- Prefer the problem each step solves over line-by-line pseudocode.

## Ablation

- State what changed relative to the full method.
- State what conclusion that change is intended to justify.
- Separate central evidence from merely supportive evidence.
