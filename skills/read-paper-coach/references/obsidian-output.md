# Obsidian Output

Use this file when the user wants the reading result turned into reusable Markdown.

## Default Paper Note

```md
# {{title}}

## 一句话主旨

## 论文要解决的问题

## 核心方法

## 输入输出 / 数据流

## loss / 关键机制

## 最核心的证据

## 局限与不确定性

## 和我当前研究的关系

## 还值得追的引用 / 相关工作
```

## Review Paragraph Note

```md
## 这一段在综述里做什么

## 本段提到的代表工作
- 文章名 / 方法名:
  - 它大概做什么
  - 它为什么在这里被提到

## 我需要记住的主线
```

## Figure Or Formula Note

```md
## 这个图 / 公式想证明什么

## 应该怎么看

## 真正要记住的结论

## 我还没搞清楚的点
```

## Compression Rules

- Prefer short headings and dense content.
- Preserve article names and method names.
- Keep evidence concrete.
- Separate `论文明确写了` from `我当前的理解`.
