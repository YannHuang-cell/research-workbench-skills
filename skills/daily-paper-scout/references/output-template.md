# Output Template

Use this compact structure for daily delivery.

```md
## 今日最值得看的

1. 论文名
- 类型:
- 为什么和你相关:
- 权威性/前沿性判断:
- 是否有代码/数据:
- 建议动作:

## Anchor papers

## Frontier papers

## Tools / Benchmarks / Reviews

## 今天建议你手动筛掉什么
```

Keep the list short enough that the user can realistically screen it in one sitting.
