# Source Strategy

Use multiple source roles rather than trusting one source for everything.

## Metadata And Recall

- Use broad metadata sources to collect candidates, years, venues, and links.
- Good for topic filters, year filters, and venue filters.

## Related-Paper Expansion

- Use recommendation or citation-network style sources to expand from seed papers.
- Good for finding adjacent work the keyword query misses.

## Frontier Monitoring

- Use recent preprint feeds or recent-publication filters to catch new work early.
- Treat these as frontier signals, not automatic authority signals.

## Resolution And Verification

- When title, DOI, or venue metadata conflicts, prefer official publisher or official metadata records.

## Practical Ranking Rule

- Start from fit.
- Then check whether the paper is anchor-like, frontier-like, or tool-like.
- Then check whether there is enough visible evidence to justify recommendation.
